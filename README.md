# 🌌・PLANET HUB
## 🛡️ Política de Privacidad

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

> ✦ **Última actualización:** 14 de octubre de 2026
>
> Bienvenido a **Planet HUB**. La privacidad de nuestra comunidad es importante. Este documento explica qué información puede recopilar y almacenar nuestro bot, cómo se utiliza y qué opciones tienen los usuarios respecto a sus datos.

### 🪐 01・Sobre Planet HUB

Planet HUB es un bot de Discord diseñado para complementar la experiencia de nuestra comunidad mediante sistemas de experiencia (XP), niveles, economía virtual, perfiles, rankings, roles automáticos, recompensas y otras funciones de participación social.

Esta política se aplica a los datos gestionados por Planet HUB a través de las funciones que ofrece.

### 📡 02・Información que podemos almacenar

Según las funciones utilizadas, Planet HUB puede almacenar las siguientes categorías de información:

- **🆔 Identificadores:** identificadores de usuario y del servidor necesarios para asociar los datos a la cuenta correspondiente.
- **💬 Actividad y experiencia:** experiencia (XP), niveles, estadísticas de mensajes y actividad registrada.
- **🎙️ Actividad de voz:** tiempo acumulado en canales de voz, cuando se utiliza para calcular experiencia o estadísticas.
- **💰 Economía virtual:** balances, transacciones, recompensas y otros datos de los sistemas económicos.
- **👤 Perfiles y rankings:** información de progresión, estadísticas y participación dentro de la comunidad.
- **🎭 Roles:** datos necesarios para gestionar roles automáticos y, cuando corresponda, conservar los roles registrados para su restauración.
- **🔗 Invitaciones:** información necesaria para las funciones de seguimiento de invitaciones y sus recompensas.
- **🟣 Presencia:** información de presencia y estado personalizado visible, cuando sea necesaria para gestionar las recompensas correspondientes.
- **⚙️ Datos técnicos:** información de eventos e interacciones necesaria para el funcionamiento y diagnóstico del bot.

La información concreta depende de las funciones habilitadas y de la configuración del servidor.

### 🔍 03・¿Para qué utilizamos los datos?

Los datos se utilizan exclusivamente para las finalidades relacionadas con el funcionamiento de Planet HUB, entre ellas:

- 📈 Calcular experiencia, niveles y estadísticas de actividad.
- 🏆 Mantener actualizados los perfiles y rankings.
- 💎 Gestionar la economía virtual y sus recompensas.
- 🎭 Asignar, actualizar o retirar roles automáticamente.
- 🔄 Restaurar roles previamente registrados cuando corresponda.
- 🔗 Gestionar invitaciones y recompensas de participación.
- 🪐 Comprobar los requisitos del sistema de recompensas por presencia.
- ⚙️ Mantener el funcionamiento y la estabilidad del bot.

### 🗄️ 04・Almacenamiento de la información

Planet HUB puede utilizar bases de datos externas, como MongoDB, para almacenar la información necesaria para sus funciones y conservarla entre reinicios.

El acceso a estos datos debe limitarse a las personas autorizadas que necesiten administrarlos o mantener el servicio.

### ⏳ 05・Conservación y eliminación

Los datos se conservarán durante el tiempo necesario para las funciones correspondientes.

Cuando dejen de ser necesarios, podrán eliminarse conforme a los procedimientos disponibles y a los requisitos aplicables.

Los usuarios pueden solicitar información sobre los datos asociados a su cuenta o pedir su eliminación mediante el canal de contacto indicado al final de esta política.

### 🔐 06・Compartición y protección de datos

Planet HUB no tiene como finalidad vender los datos personales de sus usuarios.

La información puede ser procesada por proveedores técnicos necesarios para alojar y operar el bot. Se procurará limitar el acceso a los datos y aplicar medidas razonables de seguridad para evitar accesos no autorizados.

Ningún sistema puede garantizar una seguridad absoluta.

### 📬 07・Derechos y solicitudes de los usuarios

Los usuarios pueden contactar con el equipo administrativo para solicitar información sobre sus datos o pedir su eliminación.

Las solicitudes serán evaluadas y gestionadas según las posibilidades técnicas y los requisitos aplicables.
